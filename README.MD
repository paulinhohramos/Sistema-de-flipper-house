# Sistema de Flipper House

Este sistema foi criado para facilitar para o investidor, o quanto o investimento é viavel ou não.

Tras segurança nas tomadas de decisões.

## Funcionalidades
- Cálculo de lucro na compra e venda de imóveis
- Comparação entre compra à vista e financiada
